Setup · Option 1 · Claude desktop app

Let Claude install it

You do not type commands. You paste one message into Claude Code and it does the installing, on a Mac or a PC.

1

Open Claude Code

Open the Claude desktop app and switch to Code. If it asks which folder to work in, pick your home folder.

2

Paste this message

Message to Claude
Set up video editing on this computer for me. I am not a coder, so do every step yourself and tell me in plain words what is happening.

1. Install Python 3.12, Node.js, Git and FFmpeg. On a Mac use Homebrew and install ffmpeg-full, not plain ffmpeg. On Windows use winget.
2. Download https://github.com/shasuganda/claude-edit into my home folder and install it by following its INSTALL.md, including the transcription model and the sounds.
3. Download https://github.com/shasuganda/shanley-animations into my home folder, then run "npm install" and "npm run setup" in it.
4. Run claude-edit's doctor (python tools/doctor.py) and fix every FAIL line.

Some steps take a long time. Keep going until the doctor shows 0 FAIL, then tell me it is ready.
3
About an hour · you can walk away

Say yes, then wait

Claude asks permission before it runs things. Approve each one. The FFmpeg step can sit for 20 minutes or more looking frozen. Let it finish.

4

Ready at 0 FAIL

Claude tells you when the checker passes. Close that chat; your new commands show up in the next one.

These are the same installs I did with Claude, one step at a time. I have not run this single message from start to finish myself, so if Claude gets stuck, tell it to keep going or paste the error back to it.

Setup · Option 2 · Terminal

Or copy and paste into Terminal

Open the Terminal app on a Mac, or PowerShell on a PC. Copy each block below, paste it, and press Enter. Pick your computer.

Open the Terminal app. Copy each block, paste it, press Enter, and wait for it to finish before the next one. These are the commands that worked on my Apple Silicon Mac.

1
About 2 minutes

Install Homebrew

Homebrew is a free tool that installs other tools. If typing brew --version prints a number, run only the last line.

Terminal
mkdir ~/homebrew
curl -L https://github.com/Homebrew/brew/tarball/main | tar xz --strip-components 1 -C ~/homebrew
echo 'export PATH="$HOME/homebrew/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
brew update
2
30 to 40 minutes · the long one

Install the system tools

Use ffmpeg-full, not plain ffmpeg. The plain one is missing the caption tool. This step builds some parts from scratch and looks frozen while it does. ffmpeg alone took 18 minutes on my Mac. Let it finish.

Terminal
brew install python@3.12 node git ffmpeg-full
brew link --force ffmpeg-full
3
About 5 minutes

Download claude-edit

Terminal
cd ~
git clone https://github.com/shasuganda/claude-edit.git
cd claude-edit
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
npm ci
python -m playwright install chromium
4
About 5 minutes · 2 GB download

Before your first edit

Check it works

claude-edit comes with a checker called the doctor. Claude runs it at the end of the setup. To run it again, ask Claude to "run the claude-edit doctor", or use the command below inside the claude-edit folder. Every line comes back PASS, WARN or FAIL.

Terminal or PowerShell
python tools/doctor.py
What my Mac said
24PASS
8WARN · FINE TO IGNORE
0FAIL · THIS IS THE ONE THAT MATTERS

WARN lines are optional extras. Ignore them. If you see a FAIL line, tell Claude: "the doctor shows a FAIL, fix it".

The part most people miss

Open the right folder

The /claude-edit command only exists when Claude Code is opened inside the claude-edit folder itself. In the Claude desktop app, choose claude-edit as the folder to work in, then start a new chat. In VS Code it is File, Open Folder.

your home folder

Step by step

Your first edit

Yellow dots are your turns. The rest is Claude working while you do something else.

1
You

Film your take

Vertical, with some room above your head. Keep rolling through mistakes and restarts. To try several openings, say "hook number one", deliver it, then "hook number two". Claude will ask which hook to keep.

2
You

Drop the file in the raw folder

Create a Video-Editing/raw folder inside claude-edit and put the video there. Any MP4 or MOV works.

3
You · optional

Add your inspiration

Screenshot videos whose layout, fonts, colours or style you like, and drop the screenshots into the same raw folder. Claude looks at them and asks what you like about each. A whole reference video works too. Give it now, at the start: changing the look later means Claude redoes its work. I used one screenshot and said "I like the font, font colours and placements".

4
You

Start the edit

In a new Claude Code chat, type the command with the path to your video. If the take is only your face, with no screen recording, say so in the same message.

Claude Code chat
/claude-edit "Video-Editing/raw/my-take.mp4" This is a face-only take filmed on my phone, vertical. The screenshots in the same folder are my inspiration for the graphics.
5
Claude · about 30 minutes for me

Transcribes and cuts

It removes the pauses and bad takes, then stops and plays you the cut.

6
You

Listen to the cut

Approve it, or say what was clipped. I told it one word got cut off and it fixed that join.

7
Claude

Builds a sample, then the whole video

You see a few sample scenes first. This is the moment to ask for a look. Mine: forest green, cream serif type, a yellow accent word.

8
You

Leave your notes

Open http://localhost:4750 in Chrome or Edge. Pause where you want a change, press N, type the note, then type "go" in the chat.

9
Claude

Adds sound and exports

When the picture is right, say you are happy. It adds sound, takes sound notes the same way, and saves the final MP4 in the out folder.

10
You

Send it to your phone

The out folder holds the full-quality video and a smaller phone copy. AirDrop or message the phone copy to yourself, watch it once on your phone, then post it. If there is no phone copy, ask Claude to make one.

How to open the review screen

Click the link Claude gives you

When the edit is ready, Claude says so in the chat and gives you this link: http://localhost:4750. Click it, or copy it into Chrome or Edge. In the Claude desktop app it can open in a panel beside the chat.

Closed it or can't find the link? Type in the chat: "open the review player".

What is a beat? The review screen splits your video into short sections called beats (b01, b02, b03). Each one is a few seconds where something changes on screen. A note fixes only its own beat, so changes come back in minutes, not hours.

The review screen · how to ask for a change
N
Enter
Real notes I typed · press N to add one
"I need more excitement on the font colour, like yellow maybe? It's too toned down."
"I think the text should be at the bottom of the screen, not on top."
"Add the title Editing with Claude on top of the screen, behind my head."
More ways to steer the edit

You can also do this

01Compare before and afterA beat that changed shows a Before / after button. Click it to see the old and new version side by side.
02Undo a roundIf a round of changes made things worse, type "go back one round" in the chat.
03Type notes in the chatYou do not have to use the Note button. Say it in the chat: "on beat 12, remove the bar at the bottom".
04Give Claude your own materialPhotos, clips, screenshots or links, at any point. I dropped a clip of my dog into the raw folder and said so, and Claude put it in the video.

Only if you start Claude Code from the Mac Terminal instead of the app: run source .venv/bin/activate in the claude-edit folder first.

The last step

Sound and sound effects

Sound comes last. You approve the picture first, then Claude adds the sound effects and you adjust them with notes.

01Approve the pictureWhen the video looks right, click Approved at the top right of the review screen, or tell Claude you are happy with it.
02Claude adds the effectsIt places sounds where things happen on screen: a whoosh when the layout changes, a pop when a title appears, a pencil sound on a strike-through. My video got 12.
03ListenClick the Sound button under the video, or press S, to switch from voice only to the version with the effects.
04Change what you don't likeOpen the Sound tab on the right. Click the Note button beside an effect and type what you want: "too loud", "remove this one", "use a softer sound". Press Enter, then type go in the chat.
05Ask for moreTo add an effect where there is none, pause on that moment, press N and ask for it: "add a pop here".
06Final exportOnce the sound is right, Claude builds the final video.

More sound options. You can ask in the chat to make all the effects louder or quieter at once. You can also give Claude your own sound files and ask it to use them.

No music. claude-edit adds sound effects only. Add music in Instagram or TikTok when you post; their tracks are licensed for the platform.

Your voice. Voice clean-up is not automatic. I asked for mine to be "more clear and soothing" and Claude did it. You can ask the same way.

Troubleshooting

If something breaks

These are the problems I hit on my Mac, plus one the install guide warns about.

The ffmpeg install stops with an error about openssl
Run brew update, then run the install again.
The ffmpeg install looks stuck
It is building. Mine sat for about 20 minutes with nothing moving. Let it finish.
"Your FFmpeg has no drawtext filter"
You have plain ffmpeg. Run brew unlink ffmpeg, then brew install ffmpeg-full and brew link --force ffmpeg-full.
Claude Code does not know /claude-edit
The wrong folder is open. Open the claude-edit folder itself and start a new chat.
/shanley-animate or /shanley-style is missing
Start a new chat. New commands only appear in chats opened after the setup ran.
Claude asks for "the raw OBS .mkv"
It only needs the path to your video. Any MP4 or MOV works.
Anything else
Open a Claude chat, say what happened and paste a screenshot. For a problem with the edit itself, open Claude Code in the claude-edit folder and type: "the skill isn't working, run the doctor and fix it".
